# Contributing

Personal repo; changes are made in `main` by the owner.

When editing skills:

1. Run `./tests/run-all.sh`
2. Update `routing-triggers.tsv` / `routing-triggers-en.tsv` if descriptions change
3. Keep skill bodies in English; Turkish only in `description` (`Turkish cues:`)

See `skills/writing-skills/SKILL.md` and `skills/CONSOLIDATION.md`.
