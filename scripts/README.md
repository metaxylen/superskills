# scripts

| Script | Purpose |
|--------|---------|
| `install-cursor-plugin.sh` | Copy plugin + skills to `~/.cursor/plugins/local/superskills/` |
| `link-cursor-skills.sh` | Symlink skills into `~/.cursor/skills/` (dev) |
| `link-claude-skills.sh` | Symlink skills into `~/.claude/skills/` (Claude Code) |
| `link-codex-skills.sh` | Symlink skills into `~/.agents/skills/` (Codex app) |
| `validate-skills.sh` | Runs `./tests/run-all.sh` |

See [docs/plugins.md](../docs/plugins.md).
